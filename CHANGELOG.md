#### Added

- Settings view functionality

  - Minimal Hiligaynon and Filipino translations
- Settings subviews
  - Terms of Service

### [0.1.0]-alpha.1 

#### Added

- This CHANGELOG file
- A base README file about the project
- A base CONTRIBUTING file, restricting PRs to collaborators only
- Ability to view commute routes within Leganes
- Ability to search for specific locations by name when choosing a start and end point
- Ability to choose a start and end point via the map
- A non-functional Settings view
