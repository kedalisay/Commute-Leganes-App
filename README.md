# Commute Leganes App

Helping you find your way around Leganes, Iloilo, Philippines. 🚙

## Why This Exists

There is no online information on all the existing commute routes within Leganes. This web app intends to show them through a map interface.

## Data

All data is collected manually by asking tricycle drivers and commuting the routes themselves.

See the [public routes](data/public_routes.json) and [locations](data/locations.json) files for the last updated date.

## Features

- View all commute routes under the juristiction of Leganes
- Route between two points within Leganes with consideration of commute routes
